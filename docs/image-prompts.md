# Dirección de imágenes

Herramienta: generación de imágenes integrada; sin CLI ni claves API locales. Recursos finales en public/media/. Las ilustraciones no representan clientes reales ni capturas del producto.

> Use case: stylized-concept. Asset type: wide 3D editorial illustration for Skull's software portfolio, hotel management feature. Create a sophisticated isometric architectural cutaway of a small contemporary boutique hotel: reception desk in the foreground, three guest rooms above, a subtle exterior path and landscaping. Sculptural architectural visualization, tactile cream plaster, dark graphite frames, warm terracotta accent, restrained sage greenery, natural afternoon shadows, premium detailed 3D render. Wide landscape 3:2 composition, building on right two thirds and calm negative space on left for a real interface overlay to be added in HTML. No people, no signage, no lettering, no logos, no fake app screens, no watermarks. This is an illustrative environment, not a real client property.
