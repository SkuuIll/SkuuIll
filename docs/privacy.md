# Contenido público

El portafolio presenta la identidad profesional Skull, proyectos y contacto comercial. El currículum y sus datos personales se gestionan de forma local y se envían por decisión del propietario.

No agregar descargas de documentos personales, rutas de currículum ni copias de fuentes privadas al sitio. Ejecutar npm run check:privacy y npm test antes de publicar.

La eliminación del árbol actual y del despliegue no equivale a eliminar el historial Git, ramas, artefactos o copias externas. Cualquier reescritura de historial debe prepararse con respaldo y evaluar su efecto sobre clones y referencias existentes.
