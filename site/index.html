Un ecosistema con panel web, API y app Android para conectar la gestión hotelera, las rondas de vigilancia y el control de personal.

WEB + ANDROID + API
Vigía↗
Ilustración del proyecto · Sin datos operativos

HOTELERÍA & SEGUIMIENTO GPS

Del recorrido en campo a la supervisión web.

La app del sereno registra posiciones, checkpoints, novedades y evidencias durante el turno. El panel permite revisar la última ubicación recibida, su precisión y el historial de sesiones.

El seguimiento comienza con el turno y consentimiento GPS. Los tramos sin datos no se presentan como recorridos confirmados.

Consultar por Vigía ↗
01 / HOTEL

Operación hotelera

Habitaciones, tarifas, reservas, huéspedes, check-in/check-out, cargos, pagos y caja. Limpieza y mantenimiento como parte de la operación.

02 / SEGURIDAD

Rondas & GPS

Circuitos, checkpoints, reportes y evidencias. Consulta histórica y reproducción de muestras sobre el mapa desde supervisión.

03 / PERSONAL

Asistencia & fichajes

Legajos, calendario de asistencia y registros de entrada y salida. Terminales PIN/NFC con cola offline.

04 / GESTIÓN

Administración & licencias

Compras, stock, roles y accesos por sede. Activación por instalación y módulos, con herramientas de gestión de licencias.

React · Vite · NestJS · TypeScript · PostgreSQL · Prisma · React Native · Expo · Linux · Docker

Código fuente privado. Alcance por sede, permisos y licencia; la validación operativa se realiza según los módulos contratados.

ANTES DE EMPEZAR

Lo que quizás
te estés preguntando.

¿Cuánto cuesta un proyecto?

Depende de lo que necesites. Con tu consulta podemos definir funcionalidades, alcance y una propuesta. No hay un precio único para todos los proyectos.

¿Cómo formalizamos el trabajo?

Una vez conversado el proyecto, acordamos por escrito los entregables, el presupuesto, los plazos y las condiciones de trabajo. Completar el formulario es solamente el primer contacto.

¿Podés mejorar una web que ya tengo?

Sí. Compartime el enlace, qué querés cambiar y, si lo sabés, con qué tecnología está hecha. Revisamos qué necesita y definimos las mejoras.

¿Incluye dominio, hosting y mantenimiento?

Lo definimos en la propuesta. Estos servicios y cualquier costo de terceros se detallan según lo que requiera tu proyecto.
