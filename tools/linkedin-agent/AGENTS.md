# Instrucciones para agentes de IA

Este subproyecto administra propuestas de contenido LinkedIn, NO cuentas activas.
Leer primero `SKULL_AGENT.md` y `profile/voice.md`, luego consultar los archivos originales en `upstream/skills/<nombre>/SKILL.md`.

No se permite inferir que un perfil esté actualizado o un post publicado a partir de un borrador. Las fechas del plan son propuestas.
Todo contenido debe ser basado en hechos verificables y autorizado antes de difundirse.
No ejecutar GitHub Actions para estas tareas.
