## 🧑‍💻 About me

I work with **JavaScript, TypeScript and Python**, from interfaces to backends. My work also includes mobile apps, desktop software and automation. My interests include digital products with their own identity, automation and open source development.

- **Frontend:** React, Next.js, HTML and CSS.
- **Backend:** Node.js, Python and Django.
- **Tools:** Git, Linux and Docker.
- **Collaboration:** web development, improvements to existing products and freelance projects.

## What I can build

- **Websites and web applications:** landing pages, catalogs, administration dashboards and custom tools.
- **Backends and integrations:** data management, authentication and connections between services.
- **Automation:** scripts and utilities that reduce manual steps in everyday work.
- **Existing product improvements:** new features, interfaces and maintenance.
